# Accessibility

The initial library targets relevant WCAG 2.2 AA behavior. Native controls preserve labels, validation and browser keyboard interactions. Field generates unique associations and announces errors. Button loading disables duplicate actions and announces status. Dialogs use Radix focus trapping/restoration and Escape/outside dismissal; themed portals stay inside the nearest scope. Action menus use Radix nonmodal behavior by default. Tabs use roving focus and proper ARIA relationships. ResourceExplorer uses Headless Tree plus a tested single-selection contract: arrow navigation, Home/End, activation and typeahead; disabled items are discoverable but inactive.

Automated checks cover semantic text contrast at 4.5:1 across all seven built-in themes, user-observable component behavior, keyboard navigation/focus, reduced motion, responsive modal navigation, and browser axe checks for WCAG A/AA tags including 2.2. Browser checks cover normal pages, open dialogs and menus for every preset, plus mobile navigation. Screenshots include dark/light/ocean, focus, hover, disabled/loading/error controls and responsive overlays.

No automated check certifies complete WCAG compliance. Screen-reader testing with NVDA/Firefox, JAWS/Chrome and VoiceOver/Safari has not been performed in this environment. Before broad production adoption manually verify announcements, reading order, zoom/reflow (200–400%), OS forced-colors, touch targets and touch-screen-reader behavior. Custom themes, renderLabel content, application routing and asynchronous workflows require consumer review. This is a documented validation limitation, not a claim that manual testing passed.

Presets preserve the POC forest language while raising control/readability defaults. Do not remove focus outlines. Avoid icon-only controls without names, nested interactive tree labels, unlabeled selects, excessive live regions and modal ancestors with transforms/overflow clipping. Keep destructive confirmation focus on Cancel, retain failures for retry, and provide bounded async operations.
