# Fieldnotes source audit

Audited 2026-10-16 against `/home/admin/Coding/fieldnotes`, HEAD `218bcc0` plus the existing uncommitted hosted/discovery changes. Source paths below are relative to that application. No application files were changed. This inventory describes actual UI, including inline JSX, rather than assuming a pre-existing component library.

## Architecture and visual language

The npm workspace contains a Vite/React 19 application, API and contracts packages. `src/App.tsx` owns the local Dexie workspace; `features/hosted/HostedApp.tsx` owns server workspaces through TanStack Query and the application router. Discovery pages are an additional public surface. UI is mostly inline JSX using `src/styles.css`, `features/hosted/hosted.css` and `features/discovery/discovery.css`. There is no existing Tailwind or headless component system. Lucide is the existing icon library.

The actual default is dark forest: paper #101612, panel #172019, raised #1d2a20, ink #e1ebda, muted #a4b49b, border #2c392e and accent #b1d195. Primary buttons use #172313 text, 6px corners, compact 11px type and 12px/17px padding. Headings use Georgia; body uses self-hosted Manrope. The initial light theme is a new companion, not a claim that a light POC existed. Small 8–11px labels, weak low-contrast secondary colors, global resets, hidden mobile navigation, and missing tree/menu/tab keyboard semantics need attention while retaining the palette and composition.

Keep all original application implementations functional; migration is documented and verified in independent packed-package consumers before any later application replacement.
