# fieldnotes-ui

An independent React design system extracted from Fieldnotes. Forest surfaces, quiet typography, accessible controls, and scoped runtime themes.

Under active extraction; not published. See [the inventory](docs/component-inventory.md) and [the extraction plan](docs/extraction-plan.md). The original application is not a dependency.

Tooling requires Node 24+ and npm 11.5.1+. React 19.3.1 is the initial tested runtime. Run `npm ci`, `npm run build`, `npm run typecheck`, `npm run lint`, and `npm test`.
